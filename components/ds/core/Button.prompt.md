Primary action control — buttons are "grands, très visibles" per DESIGN.md, especially on Caisse/Encaissement.

```jsx
<Button variant="primary" size="lg" iconLeft="shopping-cart">Valider la vente</Button>
```

Variants: `primary` (Bleu OBASA, default), `accent` (Orange Chantier, secondary CTAs), `secondary` (outlined), `ghost` (transparent), `danger`. Sizes: `sm` (32px), `md` (44px, default — meets 44px touch-target minimum), `lg` (56px, use for critical checkout CTAs). `fullWidth` for mobile/modal contexts.
